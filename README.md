# PULSO — descargas

Aquí se publican los instaladores de **PULSO** (visuales y control de show en directo, reactivos a la música).

**[⬇ Descargar la última versión](../../releases/latest)**

| Sistema | Archivo |
|---|---|
| Windows (recomendado) | `PULSO-Setup-X.Y.Z.exe` — se actualiza solo |
| Windows sin instalar | `PULSO-X.Y.Z-portable.exe` — avisa cuando hay versión nueva |
| Mac con chip Apple (M1/M2/M3/M4) | `PULSO-X.Y.Z-mac-arm64.dmg` |
| Mac con Intel | `PULSO-X.Y.Z-mac-x64.dmg` |
| Guía de uso con capturas | `PULSO-Guia.zip` |

Instrucciones de instalación: `INSTALAR.md` (adjunto en cada versión).

Este repositorio solo contiene las descargas; PULSO comprueba aquí si hay versiones nuevas.
